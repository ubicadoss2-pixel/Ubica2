**Nota sobre Privacidad y Aislamiento de Datos:**
Estas cuentas y sus datos asociados (eventos, ofertas, reseñas, favoritos, reservas y analíticas) son generados exclusivamente para demostración. Ninguno de estos comercios afecta las métricas ni la experiencia de los usuarios reales que se registren independientemente en la plataforma.

Para restaurar o resetear estos datos DEMO, simplemente ejecuta de nuevo el comando:
```bash
npm run db:seed:demo
```
Esto borrará iterativamente los 30 usuarios actuales junto con todas sus dependencias y los creará de nuevo desde cero, listos para tu siguiente demostración.
